# Spring-MVC-Based-Crud-Application

This project is a **CRUD (Create, Read, Update, Delete)** web application developed using **Spring MVC**. It allows basic operations such as adding, viewing, updating, and deleting records through a web interface built with **HTML, CSS, and JSP**. The application is deployed on a **Tomcat server** and developed using **Eclipse IDE** with **Spring dependencies managed through Maven**.

---

## 📌 Key Features

- Add new records
- Display a list of existing records
- Edit and update data
- Delete records
- Clean and simple user interface

---

## 🛠️ Technologies Used

- **Frontend**: HTML, CSS, JSP
- **Backend**: Spring MVC (Model-View-Controller pattern)
- **Server**: Apache Tomcat
- **IDE**: Eclipse
- **Build Tool**: Maven
- **Dependencies**:
  - Spring Web MVC
  - JSP Standard Tag Library (JSTL)
  - Servlet API
  - JDBC
  - javax-servlet
  - MySQL Connector (if using a database)

---
## 🚀 How to Run the Application

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Sourabh-Paliwal/Spring-MVC-Based-Crud-Application.git
  
2. Import the project into Eclipse:

  - Open Eclipse IDE.

  - Go to File > Import > Maven > Existing Maven Projects.

  - Select the project folder.

3. Configure Tomcat Server:

  - In Eclipse, add a new Tomcat server under Servers.

  - Right-click the project > Run As > Run on Server.

4.Database Configuration (Optional):

 - If you're using a database, configure connection details in hibernate.cfg.xml or the application properties file.

 - Make sure your database (e.g., MySQL) is running.

5.Build and Deploy:

Clean and build the project using Maven.
